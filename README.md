# CAD 图纸视觉裁切标注

一个无需安装、无需服务器的本地网页工具，用于在 CAD 导出的图纸图片上标记分区范围和切分线。

## 使用

1. 下载 `index.html`，用现代浏览器打开。
2. 点击“选择图纸图片”，导入一张或多张 CAD 导出的 PNG/JPG 图片。
3. 使用拖动、矩形框、竖线或横线标记；滚轮缩放，右侧列表可删除标记。
4. 导出 JSON、CSV 或带标记的 PNG。JSON 可再次导入恢复标记数据。

所有图像均在浏览器本地处理，不会上传。工具只记录视觉标注，不会修改或生成 CAD/DXF 几何文件。建议先从 CAD 软件导出清晰的 PNG 图片，再用本工具辅助规划分区。

## 快捷键

- `R` 矩形框
- `V` 竖线
- `H` 横线
- `Space` 拖动画布
- `Ctrl+Z` 撤销

## 隐私

仓库不包含任何项目图纸或示例图像。用户选择的图像保留在本机浏览器标签页内存中；关闭页面后需要重新选择图像。导出的标注文件由用户自行保存。
